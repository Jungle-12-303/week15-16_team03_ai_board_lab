# Project Alpha 교재

이 폴더는 Project Alpha의 구조와 구현 흐름을 순서대로 읽기 위한 문서입니다.

목표는 파일 목록을 외우는 것이 아니라, 한 기능이 화면, API, DB, AI 기능을 거쳐 어떻게 실행되는지 추적하는 것입니다. 각 장은 개념 정의, 구현 위치, 선택 이유, 적용 범위를 함께 설명합니다.

## 읽는 순서

| 장 | 문서 | 핵심 질문 |
| --- | --- | --- |
| 1장 | [시스템 전체 구조](01-system-overview.md) | 왜 프론트, 백엔드, DB, 외부 API가 분리되어 있는가 |
| 2장 | [React 프론트엔드](02-frontend-react.md) | 화면, hook, API client는 어떤 책임을 나누는가 |
| 3장 | [Spring Boot 백엔드](03-backend-spring.md) | Controller, Service, Repository, Entity는 어떻게 연결되는가 |
| 4장 | [RAG 구현](04-rag.md) | embedding, chunking, retrieval, generation은 어떻게 이어지는가 |
| 5장 | [MCP와 Agent](05-mcp-agent.md) | 외부 도구 호출과 개인화 추천은 어떻게 분리되는가 |
| 6장 | [운영과 평가](06-operations-evaluation.md) | 테스트, 평가, 배포, 비용, 보안은 어떻게 바라봐야 하는가 |

각 장의 `코드로 바로 이동` 표는 설명과 실제 구현 파일을 연결합니다. 개념을 읽은 뒤 링크된 파일을 열어 흐름을 따라가면 됩니다.

## 작성 원칙

- 사용한 기술 스택과 라이브러리를 숨기지 않습니다.
- 직접 구현한 부분과 외부 API에 의존하는 부분을 구분합니다.
- 선택한 방식의 이유와 확장할 때 바꿀 지점을 같이 적습니다.
- 구현된 범위와 아직 구현하지 않은 범위를 분리해서 적습니다.

## 먼저 알아야 할 용어

| 용어 | 이 프로젝트에서의 의미 |
| --- | --- |
| React | 브라우저 화면을 만드는 프론트엔드 라이브러리 |
| Spring Boot | Java 기반 백엔드 서버 프레임워크 |
| JPA/Hibernate | Java 객체와 MySQL 테이블을 연결하는 ORM |
| JWT | 로그인 후 API 요청마다 사용자를 증명하는 토큰 |
| Embedding | 텍스트 의미를 숫자 벡터로 바꾸는 과정 |
| RAG | 검색한 근거를 LLM에게 넣어 답변이나 초안을 만드는 방식 |
| BM25 | 단어 기반 검색 점수 알고리즘 |
| MCP | LLM 또는 애플리케이션이 외부 도구를 JSON-RPC 형태로 호출하기 위한 프로토콜 |
| Agent | 상태를 관찰하고 후보를 고른 뒤 점수화해 결과를 선택하는 실행 흐름 |
